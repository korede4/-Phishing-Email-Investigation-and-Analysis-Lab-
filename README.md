## -Phishing-Email-Investigation-and-Analysis-Lab-

A hands-on Blue Team lab focused on investigating a suspicious artefact, identifying encoded content, and using CyberChef to decode and analyze the recovered message.

# Overview

This lab involved examining a file named **The Planet Prestige** as part of a phishing email investigation.

During the investigation, an encoded message was identified within the artefact. **CyberChef** was used to decode and examine the message to better understand its contents and determine whether it contained potentially suspicious information.

# Objectives

* Examine a suspicious artefact associated with a phishing investigation.
* Identify encoded content.
* Use CyberChef to decode and analyze the content.
* Understand what the decoded message represents.
* Identify potential indicators of compromise or other suspicious information.

# Tools Used

* CyberChef
* File/artefact analysis tools

# Investigation Process

* Examined the **The Planet Prestige** file.
* Identified an encoded message within the artefact.
* Used CyberChef to decode the message.
* Reviewed the decoded content to understand its meaning.
* Considered the content for potential suspicious indicators.

# Key Point

Decoding an encoded message is only one part of the investigation. The decoded content must also be understood and analyzed to determine whether it contains suspicious indicators or provides useful information about the potential threat.

# Skills Practised

* Phishing email analysis
* Artefact examination
* Encoded data analysis
* CyberChef
* Threat investigation
* Blue Team analysis
* Security Operations (SOC) fundamentals
